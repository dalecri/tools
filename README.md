# Interactive Tools

Nine small interactive tools, trackers, and generators in one repo, each in its own folder exactly as published:

`heycristobal.com/interactive-tools/<folder>/`

| Tool | Open | About |
|---|---|---|
| Mood Tracker | [mood_tracker/](mood_tracker/) | A small daily mood tracker. |
| Typographic Weather Loom | [typographic-weather-loom/](typographic-weather-loom/) | Weather rendered as woven typography. |
| TyQuest Retro | [tyquest/](tyquest/) | A pixel task tracker made for Tyler, with room-code sync. |
| Paint Pomodoro | [paint-pomodoro/](paint-pomodoro/) | A pomodoro timer inside a natural watercolor studio. |
| Softleaf Journal | [digital-journal-app/](digital-journal-app/) | A calm journaling app. |
| Wordkeep | [castle-wordkeep/](castle-wordkeep/) | A quiet home for writing and words. |
| Little Folders | [little-folders/](little-folders/) | A tiny folder-based organizer. |
| Tamagotchi Password Generator | [tamagotchi-password-gen/](tamagotchi-password-gen/) | A password generator raised like a virtual pet. |
| Password Geode | [password-geode/](password-geode/) | A password strength assay that cracks open a crystal geode. |

## Adding a tool

1. Create a folder named for the tool and put the tool in it (entry point as `index.html`, plus any files it references).
2. Add a card for it in the root `index.html` gallery.
3. Add a row to the table above.
